## 📊 Texniki Rəqəmlər

### DolphinDB Schema

**Database:** `dfs://raw_data`  
**Partition Strategy:** Monthly VALUE (2020.01M..2030.12M)

**Table 1: raw_events**
```sql
event_id       STRING      -- Unikal ID
source         SYMBOL      -- BINANCE, IB, ...
payload        BLOB        -- Base64 raw data (byte-for-byte)
received_at    TIMESTAMP   -- Partition key
sequence_num   LONG        -- Monotonic sequence
```

**Table 2: canonical_events**
```sql
event_id              STRING
canonical_symbol      SYMBOL      -- BTC/USD (normalized)
exchange_timestamp    TIMESTAMP   -- Partition key
local_hw_timestamp    TIMESTAMP   -- HW clock
event_type            SYMBOL      -- TRADE, QUOTE
price                 DOUBLE      -- Sanitized (NaN/Inf → 0.0)
size                  DOUBLE      -- Volume
side                  SYMBOL      -- BUY, SELL
source                SYMBOL      -- Source adapter
raw_event_id          STRING      -- Foreign key to raw_events
```
